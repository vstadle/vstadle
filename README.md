# 💫 About Me:
Hi, I’m a 21-year-old cybersecurity student at INSA Centre Val de Loire.<br><br>I’m passionate about cybersecurity, low-level programming, and building secure and reliable systems. I have a strong interest in both offensive and defensive security, system internals, and secure software development.<br><br>I work mainly with C, Python, Rust, and Java. I’m comfortable in Linux environments, enjoy scripting and automation, and like working close to the system to better understand how things actually function under the hood.<br><br>I regularly improve my skills through personal projects, security challenges, and CTFs. I’m particularly interested in secure coding practices, vulnerability research, and high-performance applications written in Rust.<br><br>My goal is to become a skilled cybersecurity engineer, contribute to meaningful open-source projects, and continuously push my technical limits.<br><br>Security is not just a feature — it’s a mindset.<br>
